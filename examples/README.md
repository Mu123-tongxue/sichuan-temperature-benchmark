# Synthetic example inputs

These files are deterministic synthetic inputs created only to demonstrate the public software workflow. They are not derived from the Sichuan Basin manuscript dataset and must not be used to reproduce or interpret the manuscript's reported regional results.

- `measured_temperature_example.csv`: synthetic formation-temperature observations.
- `heat_flow_example.dat`: synthetic heat-flow nodes (`X Y Q`).
- `stratigraphic_interfaces/layer_01_example.dat`: synthetic first interface (`X Y Z`).
- `stratigraphic_interfaces/layer_02_example.dat`: synthetic second interface (`X Y Z`).

Coordinates use an arbitrary internally consistent planar coordinate system for demonstration only.
